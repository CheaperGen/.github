### Use it from your agent

Connect the hosted MCP server — sign in once in the browser, no API keys to paste:

```bash
claude mcp add --transport http cheapergen https://cheapergen.com/api/mcp
```

Or install the agent skill (Claude Code, Cursor, Codex, Gemini CLI and more):

```bash
npx skills add CheaperGen/skills
```
